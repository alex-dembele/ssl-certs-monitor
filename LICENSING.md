follows the same open-core model as OpenRisk.

**Today, every file in this repository is Community Edition (`AGPL-3.0-only`).**
The Enterprise boundary will be listed here, file by file, when the first
commercial feature lands. Until then, nothing in the repository is commercial.

## Why AGPLv3

The AGPL also covers **use over a network**: anyone who runs a modified OpenCert
as a hosted service must release their modifications under the AGPL. The
community stays free to self-host, study, modify and redistribute OpenCert, and
a competitor cannot turn it into a closed hosted service.

Copyright is held by the OpenDefender Contributors, so OpenDefender can
**dual-license** the code to customers who cannot accept the AGPL. External
contributions are accepted under the OpenDefender CLA so that this right is
preserved.
